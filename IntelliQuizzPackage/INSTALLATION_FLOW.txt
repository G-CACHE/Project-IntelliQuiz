KEY POINTS
==========

✓ Docker detection happens at TWO points:
  1. During installer setup (setup.ps1)
  2. Every time launcher runs (launch_intelliquiz.bat)

✓ If Docker is missing at EITHER point:
  - install_docker.ps1 is automatically called
  - Docker is downloaded and installed
  - No user intervention required

✓ Installation is SILENT:
  - Uses --quiet --accept-license flags
  - No user prompts during Docker installation

✓ Error handling:
  - If download fails: Shows manual download link
  - If installation fails: Suggests restart and retry
  - If startup fails: Provides troubleshooting steps

✓ Time estimates:
  - With Docker: 2-3 minutes total
  - Without Docker: 10-18 minutes total
    (3-5 min download + 5-10 min install + 2-3 min startup)


VERIFICATION COMMANDS
=====================

To verify Docker installation works:

1. On a device WITHOUT Docker:
   - Run: launch_intelliquiz.bat
   - Expected: Docker will be automatically installed

2. Check if Docker is installed:
   - Run: docker --version
   - Expected: Shows Docker version

3. Check if Docker is running:
   - Run: docker info
   - Expected: Shows Docker system information

4. Check IntelliQuiz containers:
   - Run: docker ps
   - Expected: Shows 3 running containers
     (intelliquiz_db, intelliquiz_backend, intelliquiz_frontend)
